# EV3 리모컨: 지도에서 교실 선택, 조이스틱, 속도 조절

바퀴 대신 궤도(트랙)로 움직이는 EV3 로봇용 파이썬 프로그램입니다. 로봇이 작은 웹 서버를 실행하고, 휴대폰은 일반 브라우저로 조종 화면을 엽니다. 휴대폰에 앱을 설치할 필요는 없습니다.

화면에는 탭이 세 개 있습니다.
- **교실.** 직접 그린 지도에 로봇의 위치와 교실이 표시됩니다. 지도에서 교실이나 번호 버튼을 누르면, 로봇이 지금 있는 곳에서 복도를 따라 길을 찾아갑니다.
- **조이스틱.** 손가락으로 로봇을 움직입니다. 지도 위 위치는 계속 갱신됩니다.
- **설정.** 지도 올리기, 거리 보정, 동작 설정.

**속도** 슬라이더와 빨간 **정지** 버튼은 항상 보입니다.

화면 언어(**EN / 한국어 / RU**)는 오른쪽 위에서 바꿀 수 있고, 휴대폰이 선택을 기억합니다.

다른 언어로 된 설명서: [English](README.md), [Русский](README.ru.md).

## 연결 (EV3 Classroom 프로젝트와 같음)

| 포트 | 장치 | 하는 일 |
|---|---|---|
| B, D | 궤도 모터 | 주행 |
| 1 | 초음파 센서 | 15 cm보다 가까우면 로봇이 기다림 |
| 2 | 터치 센서 | 정지 후 180° 회전 ("정지만"으로 바꿀 수 있음) |
| 3 | 컬러 센서 (바닥을 향함) | 노란 스티커로 지도 위 위치를 보정 |
| 4 | 자이로 센서 | 로봇이 바라보는 방향 (없으면 회전이 부정확함) |

## 준비물

1. **ev3dev가 들어 있는 microSD 카드.** 기본 LEGO 펌웨어로는 파이썬 서버를 실행할 수 없습니다. ev3dev.org에서 *ev3dev-stretch* 이미지를 내려받아 balenaEtcher로 카드에 쓰고 EV3에 넣으세요. 카드를 빼면 EV3는 예전처럼 EV3 Classroom과 함께 동작합니다.
   "LEGO EV3 MicroPython" 카드도 됩니다. ev3dev 기반이고 `python3`와 `ev3dev2`가 들어 있습니다.
2. **휴대폰과의 연결**, 둘 중 하나:
   - **블루투스** (따로 살 것 없음). 휴대폰에서 개인용 핫스팟을 켜세요 (안드로이드는 "블루투스 테더링"). EV3에서 *Wireless and Networks → Bluetooth*로 휴대폰과 페어링한 뒤 *Network Connection → Connect*를 누르세요.
   - **EV3용 USB Wi-Fi 어댑터** (더 안정적). ev3dev 호환 목록에 있는 제품이어야 합니다. 휴대폰 핫스팟을 켜고 EV3의 *Wireless and Networks → Wi-Fi*에서 연결하세요.

## 설치

1. `ev3robot` 폴더(`robot_server.py`와 `static` 폴더)를 EV3로 복사합니다. 같은 네트워크에 있는 Mac이나 PC에서:
   `scp -r ev3robot robot@<EV3 주소>:~/` (비밀번호 `maker`).
   VS Code의 *ev3dev-browser* 확장으로도 복사할 수 있습니다.
2. 처음 한 번만 실행 권한을 줍니다: `ssh robot@<EV3 주소>` 후 `chmod +x ~/ev3robot/robot_server.py`.
3. EV3에서 *File Browser → ev3robot → robot_server.py*를 고르고 가운데 버튼을 누르세요.
4. 처음 2초 동안은 **로봇을 건드리지 마세요**. 자이로를 보정하는 중입니다.
5. EV3 화면에 `Phone: http://172.20.10.6:8000` 같은 줄이 나옵니다. 이 주소를 휴대폰 브라우저에서 여세요.

로봇 없이 시험하려면 컴퓨터에서 `python3 robot_server.py --sim`을 실행하고 `http://localhost:8000`을 여세요. 이 모드에서는 가상 로봇이 움직입니다.

## 처음 쓸 때 순서

1. **거리 보정** (*설정*). "3바퀴 주행"을 누르고, 로봇이 간 거리를 줄자로 재서 입력하고 저장하세요. 이걸 하지 않으면 지도 위 거리가 틀립니다.
2. **방향 확인** (*조이스틱*). 위로 밀면 로봇이 앞으로 가야 하고, 지도 위 화살표도 실제 로봇과 같은 쪽으로 돌아야 합니다.
   - 뒤로 간다면: "문제 해결"을 보세요.
   - 지도 위 화살표가 반대로 돈다면: *설정 → 자이로 → 반대*.
3. **지도** (*설정*). 그린 지도를 바로 위에서 찍어 올리고, **실제 폭을 cm로** 입력한 뒤 "지도 저장"을 누르세요.
4. **교실과 복도** (*교실* 탭 → "지도 편집"). 한 번만 하면 됩니다.
   - **복도.** 복도 가운데를 따라 점을 찍으세요. 새 점은 이전 점과 선으로 이어집니다. 다른 복도로 갈라지려면 이미 있는 점을 누르고 거기서 계속하세요. "새 선 시작"을 누르면 따로 떨어진 선을 시작합니다. 로봇은 **이 선 위로만** 다니므로, 선이 벽을 지나가면 안 됩니다.
   - **교실.** 교실 문 위치를 누르고 번호(301, 302, 303…)를 입력하세요. 있는 교실을 누르면 이름을 바꿉니다.
   - **스티커.** 바닥의 노란 스티커 위치를 모두 표시하세요. 로봇이 그 위를 지나가면 위치를 바로잡아서 오차가 쌓이지 않습니다.
   - **삭제.** 교실, 복도 점, 스티커를 누르면 지워집니다.
   - "완료"를 누르세요.
5. **로봇 위치.** "로봇 위치 지정"을 누르고, 지도에서 로봇이 있는 곳을 누른 채로 로봇이 바라보는 방향으로 끄세요. 로봇이 지난번에 멈춘 자리에 있지 않다면 켤 때마다 해 주세요.
6. **출발.** 지도에서 교실을 누르고 "출발"을 누르거나, 아래의 큰 번호 버튼을 누르세요. 로봇이 복도를 따라 가장 짧은 길을 고릅니다.
   가는 도중에 다른 교실을 골라도 됩니다. 로봇이 방향을 돌려 지금 있는 곳에서 그 교실로 갑니다.

## 동작 원리

- **지도 위 위치**는 모터 회전수(얼마나 갔는지)와 자이로(얼마나 돌았는지)로 계산합니다. 이를 오도메트리라고 합니다. 오차가 조금씩 쌓이는데, 노란 스티커가 이를 바로잡습니다.
- **교실까지 가는 길.** 로봇은 가장 가까운 복도 선으로 들어가 내비게이션처럼 가장 짧은 길로 선을 따라간 뒤 교실 문 쪽으로 꺾습니다. 점과 점 사이에서는 두 궤도로 제자리 회전을 한 뒤, 자이로로 방향을 유지하며 똑바로 갑니다.
- **조이스틱을 쓴 뒤에도** 로봇은 자기 위치를 알고 있으므로 바로 교실을 고를 수 있습니다.
- **15 cm보다 가까운 장애물.** 경로를 가는 중이면 길이 비워질 때까지 기다렸다가 같은 곳에서 계속 갑니다. 조이스틱으로는 앞으로 가지 않지만, 후진과 회전은 됩니다.
- **조이스틱 안전장치.** 휴대폰 연결이 0.6초보다 길게 끊기면 로봇이 스스로 멈춥니다.
- **설정**은 로봇의 `settings.json`에, 지도·교실·복도·스티커는 `map.json`에 저장됩니다.
- **메시지**는 로봇 안에서는 영어이고, 휴대폰 화면에서는 고른 언어로 보입니다.

## 문제 해결

| 문제 | 해결 방법 |
|---|---|
| 로봇이 뒤로 간다 | `settings.json`에서 `"invert_motors"` 값을 반대로 바꾸고 프로그램을 다시 실행하세요. |
| 왼쪽과 오른쪽이 바뀌었다 (조이스틱 오른쪽이 왼쪽으로 돈다) | `settings.json`에서 `"left_port": "D"`와 `"right_port": "B"`를 서로 바꾸고 다시 실행하세요. |
| 지도 위 화살표가 반대로 돈다 | *설정 → 자이로 → 반대*. |
| 너무 많이 또는 적게 간다 | 거리 보정을 다시 하세요. |
| "복도 점들이 선으로 연결되어 있지 않습니다" | "지도 편집 → 복도"에서 선들을 하나로 이으세요. 한 선의 점을 누른 뒤 다른 선의 점을 누르면 됩니다. |
| 로봇이 벽을 가로질러 모서리를 자른다 | 모서리에 복도 점을 추가해 선이 복도를 따라가게 하세요. |
| 회전이 부정확하다 | 자이로가 포트 4에 있는지, 시작할 때 로봇이 가만히 있었는지 확인하세요. |
| 화면이 열리지 않는다 | 휴대폰과 EV3가 같은 네트워크에 있어야 합니다. EV3 화면의 주소를 확인하세요. |
| 노란 스티커를 알아채지 못한다 | 컬러 센서가 바닥 가까이(약 1 cm) 있어야 하고, 스티커는 밝은 노란색에 무광이어야 합니다. |

`settings.json`은 설정을 처음 저장하면 생깁니다. EV3에서 VS Code로 바로 열어 고칠 수 있습니다.
